# Machine Learning & Data Analysis Project

An end-to-end machine learning and data analysis project developed as part of my Computer Science studies at HIT – Holon Institute of Technology.

## Project Overview

The project covers the complete data analysis and machine learning workflow, from data collection and cleaning to exploratory data analysis, preprocessing, model development, and evaluation.

## Workflow

* Data collection and preparation
* Data cleaning and preprocessing
* Exploratory Data Analysis (EDA)
* Feature evaluation and selection
* Linear Regression baseline model
* Random Forest model development and tuning
* Model evaluation and comparison

## Results

A Linear Regression model was used as the initial baseline.
After preprocessing, feature selection, and Random Forest optimization, model accuracy improved from **75% to 78%**.

## Technologies

* Python
* pandas
* scikit-learn
* Jupyter Notebook

## Repository Structure

* `Data_Collection.ipynb` – Data collection and initial preparation
* `Data_cleaning.ipynb` – Data cleaning and preprocessing
* `EDA - Exploratory Data Analysis.ipynb` – Exploratory data analysis
* `Machine learning.ipynb` – Model development and evaluation
